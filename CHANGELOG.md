# Changelog
## Unreleased
- Bets tab: odds slider runs to +2000 (default -200 to +1000) and filters on the price the wager is sized on; **Beats best** and **Best book** removed; **Wager** sits after **Best**; the **Book** filter prices every row at the chosen book (its price shows next to Best) and includes Fanatics
- Parlays tab (after Bets): one book at a time, tick two or three of its +EV plays, every pair and the three-leg priced from the model (`odds.parlay_prob`: legs multiply, two lines on one player use his PMF), book price input (starts at the product of the leg prices), EV, Kelly, and Save to `nba/data/parlays/` (one parquet file per ticket, one row per leg, uuid `parlay_id`; `odds.save_parlay`). Results still come from the Pikkit reconcile
- Special Markets: Combined / Either for two of the game's top 8 expected shooters (`odds.combo_threes`): fair odds for combined 5+ to 9+ or either 3+ to 7+, players independent
- Tracking tab: Daily results is cumulative P&L inside a Start / Stop range (default last 7 days), one line per book in the book's color plus Total (straights + parlays; live and H2H left out), default Total only; the season cumulative line and second axis are gone. Expected vs actual and CLV each have their own book selection; `z (by date)` column (date-clustered). CLV heatmap is red / yellow / green with yellow at 0, mean CLV and n printed in each cell, cells under 5 bets faded
- Player tab: "Bets on <player> this season" is back (totals, by-side wins vs model-expected wins, every bet); line-movement chart uses the book colors (`BOOK_COLORS` in `betting/constants.py`)
- `derive_tables`: drop, rebuild and indexes for each derived table run in one transaction, so the app keeps reading the old `pgames` (and `team_def`, `opp_data`) until the new one is done, and a failed rebuild keeps the old table (`tests/test_derive.py`)
- `settle_bets`: joins `plyrLogs` on plain `player_id` / `game_date` (both TEXT, YYYY-MM-DD) instead of `CAST` / `date()`, so it uses the `(player_id, game_date)` index: 9.3s to under 0.01s on the live database; the test `bets` table now uses the prod schema
- Each tab is a fragment (`st.fragment`): a filter or widget reruns only its own tab, not the sidebar and the other three tabs; Special Markets is its own fragment too
- Query tab: ad hoc SQL on `nba.db` through a read-only connection (`mode=ro` + `query_only`), one statement per run, 30s limit, first 10,000 rows shown, CSV download, table/column reference
- Bets tab: the editor and Save Bets sit in a form, so ticks and wagers don't rerun the app until Save; a "Saved N bets" toast confirms the save; rows with no main-book price or a $0 wager are dropped
- Refresh Data (Override) clears every cached query after the data pull
- Sidebar: pending table for today's bets by book (bets, amount, total), updated on save; P&L / other / set-aside caption removed
- Player tab: one table that switches between the last-10 game log and the rolling windows, with the prediction distribution beside it (model mean and last-10 average in the corner); new last-10 chart of attempts (outlined), makes (filled) and the model's mean threes (dot)
- Tracking tab: book filter for the whole tab (other P&L only with every book selected); daily P&L with cumulative P&L on a right axis, zeros aligned (bankroll chart removed); CLV split into overs and unders, price buckets down and books across, every bet book shown with matched / placed counts
- Historical odds backfill (`nba/NBAodds.py`; books include the Kalshi and Novig exchanges and BetRivers): The Odds API historical events and event-odds endpoints into parquet by season / pull_sequence, with an events manifest, resumable task table, credit floor and per-run cap, open-line search, Pikkit bet-time snapshots, player/team alias tables, pilot report and live-lines comparison
- `--extra`: first basket, first team basket and Q1 points into `nba/data/odds_hist_extra/`, reusing the core run's events and open times; markets the API rejects are dropped before the run
- Tests for the backfill helpers (`tests/test_odds_hist.py`)
- Fixed the Fanatics bookmaker key (`fanatcis` -> `fanatics`) so live pulls return Fanatics prices
- `NAME_MAP`: Kenyon Martin Jr, Moe Wagner, Vincent Williams Jr
- `duckdb` added to the environment
- Live odds pulled as append-only parquet snapshots (nba/data/odds_live): open after the morning run, midday at 14:00 ET, close at tip - 20 min, manual from the app's Refresh Lines button
- 10 books, the same as the backfill (FanDuel, DraftKings, BetMGM, Fanatics, theScore, Caesars, Pinnacle, Kalshi, BetRivers, Novig) and 9 markets (threes, points, PRA, main and alternate; first basket, first team basket, Q1 points)
- Prices no longer averaged across main and alternate markets (pivot_table mean): the better payout is used
- Slate window computed at call time and ends 6am ET
- App reads lines from snapshots (no API call on rerun); best book is FanDuel, DraftKings or BetMGM; Fanatics shown when it beats them; theScore is information only; wager follows the best book
- `etl.fill_player_log(season)`: fills every missing regular-season player-game, one date at a time (rebounding and shot-location dashboards sum over their date range); deletes stale past placeholder rows; never overwrites a played row. `update_player_log` also runs one date at a time now (`build_player_log`)
- Removed `trade_update`, which deleted played games from the trade date on (use `Notebooks/roster_changes.ipynb`)
- Player tab (second tab in the app): choose a team, then a player from its roster; replaces the separate player page
- Daily bankroll: settled from box scores per user, 80% of profits kept (20% of each new profit high set aside)
